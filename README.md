# jQuery Studio — Assignment 6

A responsive, interactive guide to jQuery selectors, effects, DOM manipulation, and animations. The lessons include a small image gallery mini project.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension and choose **Go Live**.
3. Select a lesson from the navigation or roadmap.

The project loads jQuery 3.7.1 from the official CDN, so an internet connection is needed for the demonstrations.

## Lessons

The shared lesson page uses the `lesson` query parameter. The navigation provides a distinct URL for every assignment task:

- `task.html?lesson=0` — Setup
- `task.html?lesson=1` — Selectors & CSS
- `task.html?lesson=2` — Visibility methods
- `task.html?lesson=3` — Fade methods
- `task.html?lesson=4` — Slide methods
- `task.html?lesson=5` — Add & remove elements
- `task.html?lesson=6` — Modifying attributes
- `task.html?lesson=7` — Form interaction
- `task.html?lesson=8` — Basic animation
- `task.html?lesson=9` — Sequential animations
- `task.html?lesson=10` — Combined animation
- `task.html?lesson=11` — Interactive image gallery

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose the `main` branch and `/ (root)` as the source, then save. The site entry point is `index.html`.

## Files

- `index.html` — landing page and lesson roadmap
- `task.html` — shared lesson page shell
- `styles.css` — responsive visual design
- `app.js` — lesson content and jQuery interactions
